# Roadmap

## v0.1 — AI-Lite reference
C ABI, C++17 controller, profiles, smoothing, hysteresis, pressure governor, safe bypass, build, tests, example and integration documentation.

## v0.2 — Skyrim Snap Framegen adapter
Audit current frame_gen branch; add opt-in adapter and UI; feed real timestamp/confidence/risk telemetry; add CSV; perform deterministic A/B testing and calibrate tiers.

## v0.3 — Better motion telemetry
Forward/backward consistency, occlusion and scene-cut signals, per-region complexity aggregation, confidence calibration from real logs.

## v0.4 — Optional tiny model
Dataset and feature schema, offline training/evaluation, quantized model, optional runtime adapter, inference budget and fallback tests.

## v1.0 — Cross-host release
Stable ABI, Android ARM64/Windows/Linux builds, validated Skyrim_Android, DXVK, Winlator fork and WinNative compositor adapters.

Roadmap items are plans, not completed features.
