# Provenance and licensing notes

SnapFrame source and documentation were imported from `Snap888/Skyrim_Android`, branch `frame_gen`, commit `c385a66daef920f83a86e7eaf16ff822e507e3c7`.

The imported DXVK host depends on DXVK internal headers and types. DXVK remains a separate project with its own zlib license and attribution requirements. This repository does not include or relicense DXVK source.

Preserve the originating repository/author provenance when redistributing or porting the adapter. Review third-party licenses for every downstream integration. Do not bundle proprietary LSFG shader assets or external DLL-derived shader binaries without the required rights.
